### 关键做法：不整包下载

`Mxode/Chinese-Psychology-Books` 全包 **10GB**，但里面绝大多数是**扫描版 PDF（无文本层，抽不出字）**。
解决办法是用成熟库 **`remotezip`**（HTTP Range 读远端 zip 的中央目录），
只把 `.mobi/.epub/.txt` 成员拉下来 —— **363 个文件、585MB、11 分半下完**，省掉 9.4GB 无用流量。
脚本：`corpus/fetch_books.py`（`--scan` 只扫目录，`--only` 指定包）。

转换链路：`mobi` 包解 + `ebooklib` 读 epub + `bs4` 转纯文本，全部写进 `corpus/convert_psy.py`：

```bash
.venv/Scripts/python.exe corpus/fetch_books.py            # 拉书
.venv/Scripts/python.exe corpus/convert_psy.py --only books,psyqa,zhihu,lccc,psy-books
.venv/Scripts/python.exe corpus/build_index.py --only books --no-dedup
```

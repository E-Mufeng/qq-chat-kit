# 阶段 × 心理学机制对照：每个阶段"为什么这么说"

> 用途：把阶段策略（stage_policy.py）背后的心理学依据写清楚，让生成层知道**为什么**，
> 而不是背话术。技术必须服务于真实连接；任何让人不适的机制一律不用。

## 一、阶段—机制对照表

| 阶段 | 主导机制 | 说辞落点 | 典型反例 |
|---|---|---|---|
| 初识 | 安全感优先 + 低风险自我暴露 | 用共同来源做锚点，一句自报身份，一次只问一个开放问题 | 外貌评价、亲昵称呼、连环追问 |
| 破冰 | 互惠式自我暴露（ reciprocity of self-disclosure ） | 对方说什么，你补一句同等的自己；问具体细节不问抽象感受 | 查户口、过度关心（早点睡/多喝热水） |
| 升温 | 共谋感 + 专属标记 + 投资模型 | 内部梗、"我们俩"、请对方为你做一件小事（帮选、推荐），做完给正向反馈 | 索取隐私、直白性暗示、逼问关系 |
| 暧昧 | 张力落地 + 可得性的**稳定**而非忽冷忽热 | 具体邀约（时间+地点+可拒绝的出口），明确但不逼迫 | "不来就是不喜欢我"式道德绑架 |
| 确认 | 真诚优先，卸掉技巧 | 直接表达 + 具体安排 + 复盘感受 | 空头承诺、以关系做筹码 |
| 冷却 | 需求感管理 + 自主性展示 | 回复短但温度在，展示自己的生活节奏，不解释不追问 | 追问"为什么不理我"、长文讨好 |
| 淘汰 | 体面止损 | 一句礼貌收尾，不再主动 | 翻旧账、反复加回、泄露隐私 |

### 三条贯穿全阶段的硬规则

1. **推进靠对方的行为信号，不靠你的热情程度。** 阶段只能逐级上升（一次最多一档），
   依据是对话里真实出现的：主动回第二句、追加内容、接住梗、答应邀约意向。
2. **间歇性强化要用得克制。** 不秒回、不每条都接是可行的；但**故意忽冷忽热去"激活"
   对方的依恋系统**属于操控，明确禁用。
3. **峰终定律用在结尾：** 一段互动的记忆≈最高潮+结尾。结尾留一个可延续的钩子
   （"明天给你看个东西"），比拖长对话更有效。

## 二、依恋类型的分寸调节

先用两个连续维度判断，别贴人格标签：

- **依恋焦虑偏高**：怕被忽略。需求是**可预测的确认**。给他具体、有限、可执行的回应
  （"今晚睡前我告诉你明天的安排"），不要笼统承诺，也不要真冷处理。
- **依恋回避偏高**：怕被吞没。需求是**空间 + 返回时间**。需要暂停就说清
  "我需要半小时冷静，九点回来继续"，不要无限期消失。用小剂量自我暴露建立耐受。
- **焦虑—回避循环**：一方追问 → 一方撤退 → 追问升级 → 撤退升级。
  打断循环的唯一办法是**把抗议行为改成直接请求**（"我希望睡前能聊十分钟"），
  而不是追问"你是不是不爱我了"。

## 三、情绪支持四步（对方在倾诉/低落时）

顺序不能错；跳到"给建议"会让人觉得没被听见。

1. **确认感受**：说出他此刻的感受和触发点，不评判。
   "加班到十点，还被临时加需求，确实会崩。"
2. **具体化**：问一个能回答的具体问题，而不是"怎么了"。
   "是卡在哪个环节了？还是人已经累到不想动了？"
3. **小行动**：给一个现在就能做的动作，别给大道理。
   "先去吃点热的，剩下的明早再看，我帮你一起理。"
4. **给出口**：把决定权还给他。
   "你想我陪你吐槽一会儿，还是想自己静一静？"

反面：只接字面意思（"那你赶紧睡"）、比惨抢话（"我比你更累"）、敷衍终结（"哦，挺好"）。

## 四、冲突修复：非暴力沟通四要素（观察—感受—需要—请求）

1. **观察**（只说事实，不评判）："这两天的消息你都没回。"
2. **感受**（说自己的，不归因）："我有点不安。"
3. **需要**（说清到底要什么）："我需要知道我们之间是不是还好。"
4. **请求**（具体、可执行、可被拒绝）："今晚你有空的话跟我说一声，没空也没关系。"

禁用：翻旧账、贴标签（"你就是回避型"）、以退出要挟、在公开场合让对方难堪。

## 五、让对方为你"投资"（富兰克林效应）

人倾向于喜欢自己为之付出过心力的对象。请对方做**小而具体**的事，比单向付出更有效：

- "你眼光好，这两个颜色你帮我挑一个。"
- "你那边有没有适合周末去的地方？给我个推荐。"
- 对方给出后**必须回一个正向反馈**（用了他的建议、告诉他结果）。
- 边界：请求要小、要有真实用途，用完要反馈。被当成套路索取会立刻减分。

## 六、镜像与同步

模仿对方的语速、句式长度、标点习惯（他用"哈哈哈"你也用，他发短句你也别发长段），
能建立潜意识的亲近感。保留约三成本色——完全同步会显得假。
